cv-toolkit

Python | OpenCV | numpy | KNN | HOG | ~500 lines | 2026.08

What it does

Two modules: an image processor with chainable OpenCV operations, and a KNN image classifier built from scratch with numpy (no sklearn).

Module 1: Image processor

Wrapper around OpenCV with a fluent interface. Every method returns self so you can chain operations:

proc = ImgProcessor("photo.jpg")
proc.to_gray().gaussian_blur(5).canny(50, 150).save("edge.jpg")

Supported operations:

  • Conversion: grayscale, binary (fixed and OTSU thresholding)
  • Blur: Gaussian, median
  • Edge detection: Canny, Sobel
  • Histogram: equalization
  • Morphology: erode, dilate, open, close
  • Geometry: resize, rotate
  • Undo/redo via operation history

Module 2: Image classifier

Feature extraction

Color histogram: 32-bin histogram per RGB channel, normalized and concatenated into a 96-d vector. Captures color distribution independent of image size.

HOG: Hand-implemented Histogram of Oriented Gradients (Dalal & Triggs, 2005). Steps:

  1. Compute gradient magnitude and orientation per pixel using Sobel
  2. Divide image into 8x8 cells, build 9-bin orientation histogram per cell weighted by magnitude
  3. L2-normalize globally

KNN classifier

Brute-force Euclidean distance to all training samples. Sort distances, take top K, majority vote. K defaults to 3 (forced odd to avoid ties).

knn = KNNClassifier(k=5)
knn.fit(train_features, train_labels)
pred = knn.predict(test_feature)
accuracy = knn.evaluate(test_features, test_labels)

Data loading

load_images_from_folder() reads image folders where each subfolder is a class label. Images are resized to uniform dimensions, color histogram features extracted.

Test results

On synthetic data (red_tone / blue_tone / green_tone, 20 images each with noise), KNN with color histogram features achieves 100% accuracy. On real datasets, performance depends on the quality of feature extraction and class separability.
