cv-toolkit

Python | OpenCV | numpy | KNN | HOG | ~500行 | 2026.08

项目简介

两个模块: 图像处理器(OpenCV 链式调用)和 KNN 图像分类器(纯 numpy 手写)。延续了之前的计算机视觉期末论文方向，把课本上的 CV 算法亲手实现一遍。

模块一: 图像处理器

链式调用接口。每个方法返回 self，可以一行写完整个处理流水线:

proc = ImgProcessor("photo.jpg")
proc.to_gray().gaussian_blur(5).canny(50, 150).save("edge.jpg")

支持操作: 灰度化、OTSU 二值化、高斯/中值滤波、Canny/Sobel 边缘检测、直方图均衡化、腐蚀/膨胀/开/闭运算、缩放、旋转。可撤销(操作历史栈)。

模块二: 图像分类器

特征提取

颜色直方图: 每个 RGB 通道 32 bin，归一化后拼接成 96 维向量。不受图片尺寸影响。

HOG 特征: 手写实现(参考 Dalal & Triggs 2005)。步骤: Sobel 算子计算梯度 -> 8x8 像素 cell -> 按梯度方向(9个 bin)和大小加权投票 -> L2 归一化。

KNN 分类器

暴力欧氏距离。计算到所有训练样本的距离，排序，取前 K 个，多数投票。K 强制奇数(避免平局)。

knn = KNNClassifier(k=5)
knn.fit(train_features, train_labels)
accuracy = knn.evaluate(test_features, test_labels)

在合成数据上测试(红/蓝/绿色调各20张，加噪声)，颜色直方图特征 + KNN 达到 100% 准确率。
