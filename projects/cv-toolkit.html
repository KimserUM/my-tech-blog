cv-toolkit

Python | OpenCV | numpy | KNN | HOG | ~500 lines | 2026.08

What it does

Image processor with chainable OpenCV operations, plus a KNN classifier built from scratch with numpy.

Image processor

proc = ImgProcessor("photo.jpg")
proc.to_gray().gaussian_blur(5).canny(50, 150).save("edge.jpg")

Operations: grayscale, OTSU binary, Gaussian/median blur, Canny/Sobel, histogram equalization, erode/dilate/open/close, resize, rotate. Undo stack.

Classifier: feature extraction

Color histogram: 32-bin per RGB channel, 96-d vector. HOG: hand-implemented, Sobel gradients, 8x8 cells, 9-bin orientation weighted by magnitude, L2 normalization.

Classifier: KNN

Brute-force Euclidean distance. Sort, top K, majority vote. K forced odd.

knn = KNNClassifier(k=5)
knn.fit(train_features, train_labels)
accuracy = knn.evaluate(test_features, test_labels)
