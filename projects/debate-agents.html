debate-agents

Python | Agent | prompt工程 | 纯标准库 | ~450行 | 2026.08

项目简介

多Agent辩论系统。三个角色(方案提出者、批评者、裁判)围绕用户提出的话题进行辩论，裁判在听取双方论点后给出最终裁决。纯标准库实现，零pip依赖。

怎么工作的

用户提出话题
    |
    v
[方案提出者] 分析问题, 提出2-3个方案
    |
    v
[批评者] 找漏洞, 质疑假设, 指出风险
    |
    v
[方案提出者] 回应质疑, 修正方案    (可多轮)
    |
    v
[裁判] 听取双方, 给出最终裁决

架构

main.py      入口, 命令行参数解析
llm.py       LLM客户端(urllib直连OpenAI兼容API)
agent.py     Agent类 + 角色配置 + 对话历史管理
debate.py    辩论协调器(发言顺序控制)

三个角色

角色人格设定
方案提出者创意十足的问题解决者。深入分析, 提出2-3个方案, 说明优缺点, 用数据和逻辑支撑论点
批评者严谨的批判性思考者。找漏洞和风险, 质疑假设, 指出未考虑的边界情况
裁判公正的裁判。综合双方观点, 给出最优方案, 说明为什么以及实施注意事项

怎么跑

export OPENAI_API_KEY=sk-xxx
python -m src.main --topic "微服务还是单体架构?"
python -m src.main --topic "要不要学Rust" --rounds 3

实现细节

  • 每个Agent独立维护对话历史, 通过hear()接收别人发言, speak()生成自己的发言
  • 协调器控制发言顺序: proposer -> critic -> proposer -> critic -> judge
  • LLM客户端用urllib直连OpenAI兼容API, 不依赖openai/httpx等第三方包
  • 角色人格全部通过system prompt设定, 没有硬编码行为逻辑
