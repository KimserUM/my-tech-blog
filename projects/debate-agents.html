debate-agents

Python | Agent | prompt engineering | stdlib only | ~450行 | 2026.08

项目简介

多Agent辩论系统。3个role(Proposer/Critic/Judge)围绕topic进行debate，Judge听取双方argument后给出final verdict。纯标准库，零pip dependency。

work流程

用户提出topic
    |
    v
[Proposer] 分析问题, 提出2-3个proposal
    |
    v
[Critic] 找漏洞, 质疑assumption, 指出risk
    |
    v
[Proposer] 回应质疑, 修正方案    (可multi-round)
    |
    v
[Judge] 听取双方, 给出最终verdict

架构

main.py        CLI入口 + arg parsing
llm.py         LLM client (urllib直连OpenAI compatible API)
mock_llm.py    Mock LLM (预设回复, demo用, 不花钱)
agent.py       Agent类 + role config + history管理
debate.py      Coordinator (发言顺序 + round控制)

三个Role

RolePersonality设定
Proposercreative problem solver。深入分析, 提出2-3个proposal, 说明trade-off, 用data和logic支撑论点
Criticrigorous critical thinker。找漏洞和risk, 质疑assumption, 指出未考虑的edge case
Judge公正的裁判。综合双方argument, 给出最优方案, 说明why以及implementation注意事项

怎么跑

# mock mode, 不需要API key
python -m src.main --topic "要不要学Rust" --mock

# 真调API
export OPENAI_API_KEY=sk-xxx
python -m src.main --topic "微服务还是单体?" --rounds 3 --stats

# 自定义role
python -m src.main --init-config roles.json   # 导出配置模板
python -m src.main --topic "..." --config roles.json --mock

# 导出debate记录
python -m src.main --topic "..." --mock --output debate.txt

实现细节

  • 每个Agent独立维护conversation history, hear()接收别人speak, speak()生成自己发言
  • Coordinator控制发言顺序: proposer -> critic -> proposer -> critic -> judge
  • LLM client用urllib直连OpenAI compatible API, 不依赖openai/httpx等第三方package
  • Role personality全部通过system prompt设定, 没有hardcode行为逻辑
  • Mock mode用预设reply模板, 演示完整debate流程不需要花API费用
