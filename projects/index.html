mini-http-server

C socket pthread 线程池

从零手写的HTTP服务器。用C语言实现了TCP监听、HTTP请求解析、路由分发、 静态文件服务、线程池、Keep-Alive等功能。

写这个项目的起因是计网课学了TCP/IP但从来没写过socket代码。 踩了不少坑: 端口复用、浏览器双重请求、pthread_detach内存泄漏...

mini-kvstore

Python Raft 分布式 WAL

分布式KV存储引擎。基于Raft共识算法实现了Leader选举和Log复制。 存储层用WAL(预写日志)+快照保证持久化，网络层用自定义TCP协议通信。

写的时候最大的感受: 分布式系统的难点不在算法本身(论文才10页)， 而在各种边界条件——term检测、选举分裂、日志冲突。

mini-sql

Python 编译原理 SQL

手写SQL解析器和执行引擎。包括: 手写状态机做词法分析、 递归下降parser构建AST、内存表执行引擎。

支持SELECT/INSERT/CREATE/DELETE + WHERE + ORDER BY + LIMIT。 做这个的时候顺便复习了编译原理(原来是这么回事)。

cv-toolkit

OpenCV KNN HOG

图像处理工具集。OpenCV链式调用(灰度化/滤波/边缘检测/形态学) 再加上纯numpy实现的KNN分类器。

延续了之前的CV论文方向，把课本上学的图像处理算法都亲手实现了一遍。
