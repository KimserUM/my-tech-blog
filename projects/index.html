2026 年考研复试准备的六个项目

以下项目均从旧 GitHub 账号于 2026-08-03 迁移至当前账号。实际开发跨度约两个月(6月中旬-8月初)。

mini-http-server

C 语言 · socket · pthread · 线程池 · ~1200行 · 2026.06-07

从零实现的 HTTP/1.1 服务器。TCP 监听、HTTP 请求解析、线程池并发、静态文件服务、Keep-Alive 支持、文件上传接口。搭配计算机网络和操作系统知识点复习。

mini-kvstore

Python · Raft 共识 · WAL · TCP · ~1500行 · 2026.07

分布式 KV 存储引擎。基于 Raft 算法实现 Leader 选举和日志复制。WAL 持久化 + 快照压缩保证数据安全。自定义 TCP 协议帧用于节点间通信。

mini-sql

Python · 词法分析 · 递归下降 · 执行引擎 · ~1100行 · 2026.07-08

手写 SQL 解析器和执行引擎。手写状态机做词法分析、递归下降 parser 构建 AST、内存表执行引擎。支持 SELECT/INSERT/CREATE/DELETE + WHERE + ORDER BY + LIMIT。

cv-toolkit

OpenCV · numpy · KNN · HOG · ~500行 · 2026.08

图像处理工具集 + 纯 numpy 实现的 KNN 分类器。OpenCV 链式调用(灰度化/滤波/边缘检测/形态学)，手写 HOG 特征提取，KNN 分类器。
