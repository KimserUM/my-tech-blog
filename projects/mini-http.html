mini-http-server

C | socket | pthread | thread pool | ~1200 lines | 2026.06-07

What it does

A from-scratch HTTP/1.1 server written in C. Listens on a TCP port, parses HTTP requests, serves static files, and exposes JSON API endpoints.

Architecture

main.c        - entry point, signal handling
server.c      - TCP socket, thread pool dispatch
http.c        - HTTP request parsing, response building
threadpool.c  - producer-consumer thread pool (mutex + cond)

HTTP parsing

Manual state machine. First line parsed with sscanf. Headers split on colon. Body separated by double CRLF. Content-Length for body size.

Thread pool

typedef struct {
    pthread_t workers[8];
    task_t    queue[64];
    int       front, rear, count;
    pthread_mutex_t lock;
    pthread_cond_t  not_empty, not_full;
    int       running;
} threadpool_t;

Keep-Alive

Connection: keep-alive keeps socket open for multiple requests (max 50 per connection).

API endpoints

  • GET /api/time — server timestamp
  • GET /api/stats — thread pool status
  • POST /api/echo — echo POST body
  • POST /api/upload — multipart file upload

Problems

  • SO_REUSEADDR for port reuse on restart
  • Chrome double-request (favicon) deadlocked single thread
  • send() partial writes need loops
  • Windows binary fopen "rb" for images
  • Path traversal: is_safe_path() blocks ".."
